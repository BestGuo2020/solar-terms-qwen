# 二十四节气 · 地球公转互动科普

一个基于 **Three.js + Vue 3 + Vite** 的互动科普网站：用太阳—地球—公转轨道的三维场景，
直观展示**二十四节气、太阳黄经与季节变化**之间的关系，并完整介绍二十四节气的
**历史渊源、文化价值与节气歌**。

打开页面即显示**当前真实日期**对应的地球轨道位置与所处节气；所有对用户显示的节气时刻
统一换算为**北京时间（Asia/Shanghai, UTC+8）**。

## 一、运行方式

```bash
# 1. 安装依赖（Node ≥ 18；仓库已带 .npmrc，把 npm 缓存指向项目内 .npm-cache）
npm install

# 2. 开发模式（热更新）
npm run dev            # 默认 http://127.0.0.1:5173/

# 3. 生产构建 + 本地预览
npm run build
npm run preview        # 默认 http://127.0.0.1:4173/
```

纹理已在构建准备阶段预先下载到 `public/textures/`（见 `public/textures/CREDITS.json`），
**运行时不依赖任何第三方 CDN**。如需重新下载（例如补充高清底图）：

```bash
npm run fetch:textures
```

### 自检 / 验收

```bash
npm run verify          # = verify:astro + verify:scene + verify:content
npm run verify:astro    # 交节时刻：与库内 Seasons() 逐年交叉校验（1901–2200）、
```

## 三、关键实现说明

### 1. 唯一的"模拟时间"真值

`src/lib/simClock.js` 中的 `clock.nowMs`（UTC 毫秒）是全站唯一时间源。
3D 场景每帧读它；Vue 侧通过 10 Hz 节流的响应式快照 `ui` / 派生 `sim` 更新界面。
时间轴、动画、详情、列表、节气歌联动全部由它派生，**不存在第二套时间计算**。

- `playing + speed` 驱动公转（模拟秒/真实秒，档位从"实时"到"1 年/秒"）；
- `rotationMode`（演示自转 / 真实自转 / 停止）**独立**控制自转——需求要求公转与自转分别可控；
  "真实自转"用格林尼治视恒星时（GAST）驱动，一个恒星日 = 23h56m04s（已校验）。
- 偏离真实时间超过 90 秒即标注"**模拟时间**"并给出偏离量。

### 2. 天文历算（不是查固定日期表）

`src/lib/astro.js`：

- 太阳位置取 **astronomy-engine** 的 `SunPosition()`，即**地心视黄经**
  （apparent geocentric ecliptic longitude of date，含光行差与光行时改正）——这正是节气的定义量；
- 交节时刻用**二分法反解"视黄经 = 目标值"**（`findSunLongitude`），收敛到 <20 ms；
  月/日只作为搜索种子，绝不参与结果；
- 与库自带的 `Seasons()`（独立实现的分至点）在**开放区间 1901–2200 全部 1200 个分至点**上交叉校验，
  最大偏差 **0.006 秒**；
- 与**香港天文台**公布的 2026 年秋分（数据源 HMNAO/USNO）相差 **0.62 秒**；
  与**紫金山天文台**发布的 2026 年 24 个节气逐一对比，偏差均 **≤ 60 秒**（参考表只精确到分钟）；
- 北京时间换算走 `Intl` 的 `Asia/Shanghai`，并对 1986–1991 年中国夏令时做了往返校验；
- 支持年份 **1–8800**（"赛博永生"档），按四级精度披露：
  **1901–2100** 与权威历书比对到分钟以内；**1600–2200** 历算可靠（ΔT 为拟合/混合式）；
  其余年份 ΔT 为外推式（2150 年后为长期抛物线）、岁差与历法漂移增大，
  页面给出 ±不确定度并建议切换**动力学时 TT**（TT = 民用时 + ΔT，不依赖地球自转，远年更可靠）。
  上界 8800 的理由：约 8900 年后格里历（365.2425 d）相对回归年（365.24219 d）的漂移
  叠加 ΔT 增长，会使"某年的小寒"漂出 1 月、不再良定义；公元前不开放是因为历法回溯与
  "统一时区"只是人为约定。年份下拉只列 1901–2200，更远/更早用"任意年份"数字输入框；
  越界输入会被夹到 [1, 8800]。

### 3. 太阳黄经 ↔ 3D 场景坐标的对应关系（最容易出错的一层）

`src/three/orbitMath.js` 是唯一换算层，约定写在文件头：

- 场景右手系、Y 轴向上；**黄道面 = XZ 平面**，**+X = 春分点 ♈**，**+Y = 黄道北极**；
- 黄经 λ 的点 = `(r·cosλ, r·sinβ, −r·sinλ)`（z 取负号保证从北天极俯视为**逆时针**，与真实一致）；
- 地球日心黄经 `L⊕ = λ☉ + 180°`，故地球位置 = `eclipticToScene(λ☉+180°, R)`；
  节气标记画在"该节气交节时地球所在处"，因此**地球走到标记处即交节**；
- 地轴 = 北天极方向 = 黄经 90°、黄纬 90°−ε；倾角放在**只平移、不随公转旋转**的父节点里，
  所以地轴在空间中**指向恒定**，不会始终朝向太阳；
- 页面 HUD 同时显示 **λ☉** 与 **L⊕（场景方位角）**，并注明两者相差 180°，避免混淆。

`npm run verify:scene` 与浏览器验收脚本共同校验：

- 春分地球在 −X、夏至 +Z、秋分 +X、冬至 −Z（λ☉ 恰为 0/90/180/270 时位置误差 < 0.02）；
- 夏至直射 +23.436°N、冬至 −23.436°S、两分 0°（与 sin δ = sin ε·sin λ☉ 独立公式一致）；
- 夏至北极向日（点积 +0.398）、冬至背日（−0.398）、两分垂直（≈0）；
- 夏至 80°N 极昼 / 80°S 极夜，冬至相反，两分全球昼夜各 12 h；40°N 夏至 14.8 h、冬至 9.2 h；
- 四个分至点的地轴方向**完全相同**（偏差 0）；
- 直射点经度 = 太阳赤经 − GAST，120 个时刻最大偏差 0.0000°。

### 4. 渲染与性能

- 地球：自定义着色器（昼/夜贴图混合 + 晨昏线 softstep + 晨昏暖色散射 + 海面镜面高光 +
  边缘大气 fresnel）；云层与大气为独立球壳；太阳为自发光着色器（米粒组织流动 + 临边昏暗）+ 双层光晕；
- 点光源位于太阳（原点），与地球着色器的 `uSunDirW` 同源，**光照方向与受光面永远一致**；
- 画质三档（高/中/低）：像素比、球面分段、云/大气/星空点数、标签密度随之调整；
  帧率持续低于 28 fps 时自动降档并提示（可用 `?nodegrade=1` 关闭、`?q=high|medium|low` 固定）；
- `document.hidden` 时完全停帧；3D 区滚出视口时只跳过渲染、时间照常推进；
  组件卸载时释放几何体/材质/纹理/控制器/渲染器并移除 DOM；
- 8k 地球底图仅在 `MAX_TEXTURE_SIZE ≥ 8192` 且画质为"高"时加载，否则用 2k。

### 5. 交互与可访问性

- 视角：鼠标拖动旋转、滚轮缩放；触屏单指旋转、双指缩放平移（OrbitControls）；
  提供**轨道总览 / 北极俯视 / 地球近景 / 恢复默认视角**；
- 场景右下角常驻的只有**一条视角分段控件**（默认/总览/俯视/近景/重置）和**一颗 ⚙ 圆形按钮**：
  点开 ⚙ 是分组弹出面板（辅助标识 / 标签密度 / 画质 / 保存），默认收起，开合偏好记在 localStorage；
  左下天文读数默认单行，点击展开坐标映射说明。
  这样 3D 画面常驻的只有"节气卡片 + 时钟 + 单行读数 + 视角条 + 一颗按钮"；
  面板带 `aria-expanded` / `aria-controls`，键盘可达；移动端 HUD 整体排到场景下方。
- 轨道上 24 个节气标签是**真实 DOM 按钮**（CSS2DRenderer），可点击、可 Tab 聚焦、回车跳转；
  3D 标记点同时支持射线拾取；点击即**暂停播放并跳到该年该节气的交节时刻**；
- 时间轴是 `role="slider"`，支持拖动与 ←/→（Shift 按天）键盘操作；
- 3D 区聚焦后：空格播放/暂停、←/→ 步进、Home 回到今天、V 切视角、H 开关辅助标识；
- 移动端把 HUD、控制区改排到场景**下方**，不遮挡地球与轨道。

## 四、模型简化与数据精度（务必阅读）

1. **尺寸与距离不按实际比例。** 真实太阳直径约为地球的 109 倍、日地距离约为地球半径的
   23481 倍；按真实比例地球在画面里不足一个像素。场景保留了两个与季节成因直接相关的特征：
   **轨道接近圆形**与**黄赤交角约 23.4°**（按模拟时刻实时计算，当前约 23.436°）。
2. **轨道按正圆绘制。** 真实偏心率 0.0167，近日点在 1 月初、远日点在 7 月初；
   这正是"节气间隔不等于 15 天"的原因之一（冬半年约 14.7 天、夏半年约 15.7 天）。
   节气判断只依赖太阳黄经，不受该简化影响。
3. **交节时刻精度**：秒级（二分收敛 <20 ms；与权威发布值偏差 ≤1 分钟，分至点 <1 秒）。
   页面显示到分钟，详情区显示到秒。
4. **岁差/章动**：一年内对地轴指向的影响 <1e-4°，场景中按常量处理（符合真实）；
   春分点在数千年尺度上的西移不影响回归年与节气日期，科普区已说明。
5. **自转**："真实自转"严格跟随模拟时间（GAST）；"演示自转"约 24 秒一圈，仅为便于观察，
   界面上已明确标注两种模式。
6. **程序化替代纹理**：若某张纹理缺失/加载失败，自动改用 `src/three/proceduralTextures.js`
   生成的等效纹理并提示；其中程序化"地球"只是类地行星示意，**不代表真实海陆分布**。
7. 历史与文化内容为科普表述；年代、文献、申遗信息以页面"参考来源"为准，
   学界存疑处（如《吕氏春秋》节气数目、《淮南子》今本次序、启蛰/惊蛰避讳细节等）均随条标注。
